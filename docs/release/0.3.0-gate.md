# 0.3.0 personally usable gate

**Completed:** 2026-07-28
**Scope:** SFT-025 through SFT-037
**Release action:** No tag, image, artifact publication, or public-release claim

This gate establishes that the accepted `PRODUCT.md` §19.3 scope is suitable
for private administrator dogfooding. It does not satisfy the `0.4.0`
backup/recovery/hardening milestone or any public-release gate.

## Cumulative verification

The gate reran the repository against Go 1.26.5 on linux/amd64:

```bash
go fmt ./...
go vet ./...
go test -count=1 ./...
go test -race -count=1 ./...
node --check internal/web/ui/assets/tokens.js
make frontend-check
make playwright
git diff --check
```

All commands passed. The race run includes the controlled writer, Live broker
stress, subscription churn, SSE revocation/overflow, source mutation,
retention/ingestion/read interleaving, atomic settings updates, status
recording, and browser-session/History concurrency. All 16 Chromium scenarios
passed in 46.7 seconds.

The production-path Go suite builds and launches the real binary, creates
administrator/Server/token state through supported CLI paths, ingests plain,
gzip, Coolify, generic Fluent Bit, duplicate, and retry cases through the
ingestion listener, stops and restarts the process, then verifies durable
SQLite results. Separate application lifecycle tests prove queued writes drain
before Live shutdown, health transitions remain minimal, shutdown is bounded,
and the owner-only control socket is removed.

Fresh schema creation, no-op reopen, in-test schema-one and schema-two upgrade
fixtures, representative Server/administrator preservation, integrity checks,
migration rollback, contiguous numbering, critical index use, and
schema-too-new refusal all pass. Persistent released-version fixture files are
an accepted `0.4.0` requirement; there is no `0.3.0` schema migration.

## Integration and operational review

- The generated Coolify and generic configurations were rerun through rootless
  Podman using the pinned images. Fluent Bit `v2.0.14` and `v5.0.9` both
  reported `configuration test is successful`; `bash -n` accepted the
  generated curl workflow.
- Coolify's exact `COOLIFY_APP_NAME=siftail-self` exclusion remains anchored
  and ordered before rename. Structural and runtime tests reject recursive
  self-ingestion while preserving similarly named ordinary applications.
- Queue event/byte saturation, broker command/event/byte saturation, connection
  limits, slow SSE writes, client cancellation, writer shutdown, and retention
  busy-reader behavior fail explicitly without unbounded allocation.
- Retention uses age or active-footprint size, canonical oldest-first ordering,
  bounded transactions, passive/truncate checkpoints, and incremental vacuum.
  No routine full `VACUUM` or audit/session deletion was introduced.
- Live publication remains post-commit and nonblocking. Clear view is
  browser-only; source purge/removal and retention publish explicit controls.
- The status surface and health endpoints expose only bounded operational
  facts. Tests search process logs and browser output for payload, token,
  session, SQL, path, and upstream-body leakage.

## Security, privacy, and design review

- [x] All UI state changes retain session, CSRF, exact Origin/Referer, request
  limit, panic-recovery, and strict security-header middleware.
- [x] Ingestion authentication remains independent and token-bound; payload
  metadata cannot select a Server.
- [x] Plaintext ingestion tokens occur only in immediate CLI/stdout or one-time
  browser state. Generated previews retain a placeholder; navigation and
  session expiry remove the plaintext.
- [x] The guided test is an explicit administrator action, ignores ambient
  proxy variables, refuses redirects, bounds time/body consumption, and makes
  no background or ordinary-operation outbound call.
- [x] Hostile messages, aliases, hierarchy labels, and attributes remain
  escaped text. Browser code uses text nodes/value assignment and does not put
  event content through `innerHTML`.
- [x] Keyboard focus, filter shortcuts, expansion/collapse, confirmations,
  token reveal/copy, and fragment focus restoration are covered.
- [x] Dark desktop and light 390 px states pass WCAG 2.0/2.1/2.2 A/AA axe
  smoke checks. Severity text and status labels do not rely on color alone.
- [x] Reduced-motion behavior is computed in Chromium; Live adds no per-event
  animation and retains scroll ownership when the administrator scrolls away.
- [x] Mobile screenshots for History details, Live, Sources, Servers,
  retention settings, status, and generated ingestion guidance were reviewed.
  Page-wide horizontal overflow is absent; long payload/config blocks scroll
  locally.
- [x] Assets, fonts, scripts, and styles remain embedded with no CDN,
  telemetry, analytics, or production Node runtime.

## Dogfood boundary and known limitations

- This is the first personally usable target, not a public release. No tag,
  `latest` image, or support promise is created by this gate.
- An actual supported Coolify host was not available. The pinned upstream
  images, production ingestion path, generated configuration, and
  self-exclusion were tested locally; installation on Coolify remains an
  operator dogfood step.
- Backup, verification, restore, formal operational diagnostics, audit
  history, export, disk-full degraded-mode completion, persistent migration
  fixtures for released versions, and the broader security review belong to
  `0.4.0`.
- A manual screen-reader session and 200% browser-zoom session were not
  performed. Semantic landmarks/names, keyboard focus, 390 px reflow, local
  scrolling, contrast, and automated axe checks pass.
- The 10-million-event History tier, production-container measurements,
  multi-architecture packaging, long soak, burst, and complete release
  procedures remain later pre-public/stable-release gates.
