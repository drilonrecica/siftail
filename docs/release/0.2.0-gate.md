## Browser method and results

Development-only dependencies are locked to `@playwright/test` 1.62.0 and
`@axe-core/playwright`/`axe-core` 4.12.1. The suite builds the Go binary, creates
the administrator, Server, and ingestion token through production CLI paths,
starts the production server, ingests 220 ordinary and hostile events through
the public ingestion endpoint, and removes its process, socket, database,
binary, and temporary directory in global teardown.

Commands run:

```bash
npm ci --ignore-scripts
make frontend-check
SIFTAIL_PLAYWRIGHT_CHROMIUM=/usr/bin/chromium-browser make playwright
```

All seven Chromium scenarios passed in 22.2 seconds. The final command result
is recorded in `TASKS.md`. Screenshots are written to
`.playwright-artifacts/` for CI/human review and are ignored by Git; no source
snapshots are maintained.

The suite covers native login/logout, canonical defaults, source/time/level/
stream/text filtering, URL Back restoration, cursor append, hostile details,
clipboard text, session invalidation, uniform/throttled failure, keyboard
focus, dark/light, reduced motion, 390px inspection, and WCAG 2.0/2.1/2.2 A/AA
axe smoke checks. Clock-controlled Go tests remain authoritative for exact
expiry boundaries; the browser verifies the resulting invalid-session redirect.

## Security, accessibility, and presentation checklist

- [x] Native login and logout satisfy exact same-origin validation.
- [x] Cross-origin Origin/Referer negatives and untrusted proxy spoofing are
  covered by Go tests.
- [x] CSP, frame, MIME, permissions, opener, resource-policy, HSTS, cookie, and
  no-store behavior are covered by Go tests; Playwright asserts the main CSP
  and frame boundary.
- [x] Hostile `<script>`, `<img>`, nested attributes, and multiline content
  remain text; application JavaScript contains no event-data `innerHTML`.
- [x] Keyboard focus reaches filters/details and returns to the row control.
- [x] Axe smoke checks pass in dark desktop and light 390px detail states.
- [x] Dark/light token review includes severity text, muted metadata, focus,
  and selected/hover surfaces. The gate corrected light muted/amber contrast.
- [x] Reduced-motion CSS is active.
- [x] 390px emergency inspection has no page-wide horizontal overflow; raw
  detail blocks retain local scrolling.
- [x] Human-review screenshots are CI artifacts, not repository snapshots.
- [ ] A manual screen-reader session and 200% browser-zoom session were not
  performed in this automated environment. Semantic landmarks, names, focus,
  mobile reflow, and axe checks passed; these manual checks remain pre-public
  review items and are not `PRODUCT.md` §19.2 functional requirements.

## Performance and concurrency

The query gate rerun and exact results are in
[`../performance/history-queries.md`](../performance/history-queries.md).
Plans remained on the existing time/source indexes; no migration or index was
added. The documented 10-million-row measurement remains a pre-public gate.

`TestConcurrentSessionLookupAndHistoryReads` runs 16 workers with 50 iterations
each against real migrated SQLite, combining opaque-session lookup with bounded
History reads. It passed under the race detector. Existing revocation-race and
query-cancellation tests remain in the cumulative suite.

## Development dependency and resource impact

- `@playwright/test`, `playwright`, and `playwright-core` 1.62.0 are
  Apache-2.0; they provide browser orchestration unavailable in the Go runtime.
- `@axe-core/playwright` and `axe-core` 4.12.1 are MPL-2.0; they provide
  automated accessibility rules. `fsevents` 2.3.2 (MIT) is an optional
  macOS-only transitive dependency.
- `npm ci --ignore-scripts` installed 22 MiB of development modules on the
  measured host, excluding a browser binary. `npm audit` reported zero known
  vulnerabilities on 2026-07-28.
- CI downloads Chromium for the browser job. Local verification may point
  `SIFTAIL_PLAYWRIGHT_CHROMIUM` at an installed Chromium. These variables are
  stripped before starting Siftail and do not expand its configuration.
- Node.js, packages, browsers, reports, traces, and screenshots are absent from
  the production Go binary and ordinary runtime. There is no binary/RSS/disk
  impact on deployed Siftail and no public API expansion.

## Measured limitations

- Browser timing is a smoke gate, not a latency benchmark.
- Exact time expiry is not made flaky with wall-clock browser waits; controlled
  Go-clock tests cover the boundary.
- The 10-million-event query tier, manual screen-reader check, and manual 200%
  zoom check remain pre-public gates.
