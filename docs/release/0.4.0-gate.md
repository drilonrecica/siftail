# 0.4.0 pre-public hardening gate

**Completed:** 2026-07-28
**Scope:** SFT-038 through SFT-049
**Release action:** No tag, image, artifact publication, `latest` update, or
public-release claim

This gate establishes traceable implementation and recovery evidence for the
accepted `PRODUCT.md` §19.4 scope. It closes the backup, recovery, diagnostics,
audit, export, degraded-storage, migration-fixture, failure-path, and security
hardening milestone. Public packaging, deployment documentation, production
container measurements, soak testing, and interface polish remain the
dependency-ordered `0.5.0` milestone.

## Cumulative verification

The gate ran on Fedora Linux 44, Linux 7.1.5 x86-64, an Intel i5-7500 with four
logical CPUs, Go 1.26.5, Node.js 22.22.2, and npm 10.9.7:

```bash
make check
go test -race -count=1 ./...
go test -count=1 ./internal/database ./internal/backup
go test -count=1 ./cmd/siftail ./internal/app
go test -count=1 ./internal/audit ./internal/auth ./internal/ingest \
  ./internal/logs ./internal/retention ./internal/status
go test -run '^$' -bench . -benchtime=1s -count=1 -benchmem \
  ./internal/audit ./internal/auth ./internal/backup ./internal/database \
  ./internal/ingest ./internal/logs ./internal/retention ./internal/sources
make frontend-check
make playwright
go run golang.org/x/vuln/cmd/govulncheck@v1.6.0 ./...
npm audit --omit=optional
git diff --check
```

All commands passed. `make check` verified formatting, vet, all Go tests, and a
metadata-bearing production build. The build was 19,620,368 bytes. The
uncached race run passed every package. The focused database/backup command
reran the fresh install, schema-1–4 migration matrix, failed migration rollback,
newer-schema refusal, and schema × full/configuration backup/verify/restore
matrix. The command/ application suites reran supported CLI subprocess smoke,
real listener ingestion, restart, health, control-socket, graceful queued
shutdown, recovery, and maintenance-owner paths.

All 19 single-worker Chromium scenarios passed in 59.5 seconds. They include
axe, keyboard/focus, dark/light, reduced motion, 390-pixel mobile layout,
hostile data escaping, session invalidation, strict headers, audit, backup,
export, retention, Live, and authenticated failure recovery.

`npm audit` found zero vulnerabilities. `govulncheck` found zero vulnerabilities
in called symbols or imported packages. Its module scan additionally identifies
`GO-2026-5932` because `golang.org/x/crypto` contains the deprecated
`openpgp` package; Siftail does not import or call that package and uses its
maintained Argon2id implementation.

## Failure and recovery matrix

- Fresh/current/corrupt/newer SQLite startup preserves data and never silently
  recreates, deletes, or down-migrates a database.
- Every supported migration fixture reaches the current schema with exact
  ordered migration history, representative data preservation, integrity, and
  critical post-upgrade reads/writes.
- Full and configuration backups are produced while ordinary writes continue,
  are accepted only after final verification, never overwrite raced targets,
  and remove invalid partial/final artifacts.
- Restore refuses an active server and unsafe inputs, preserves the previous
  database as a verified session-free rollback, and automatically reinstalls
  and validates it after injected post-install failures or cancellation.
- Disk-full and temporary write faults reject ingestion explicitly without
  decoding known-degraded payloads. Read paths remain available where SQLite
  permits, and only a committed bounded transaction clears degradation.
- Export never sends a partial or unaudited artifact. Limits, cancellation,
  audit failure, response failure, and hard-interruption staging are covered.
- Retention deletes canonical oldest events in bounded coordinator
  transactions, publishes only after commit, stops for busy checkpoints, and
  never performs routine full `VACUUM`.
- Graceful shutdown stops admission, drains accepted writer work, publishes
  committed events, closes Live with a control frame, checkpoints, and exits
  within its configured bound.

## Manual security, privacy, and accessibility review

- [x] Backup, rollback, and export artifacts use private staging, explicit
  verification, safe names, no-overwrite publication/response boundaries, and
  documented protection requirements.
- [x] Restore is stopped-server CLI only, requires exact confirmation, removes
  sessions, preserves a verified rollback, and publishes no raw path or SQLite
  error.
- [x] Audit and diagnostic metadata are typed and bounded. Application
  messages, attributes, raw payload, query text, credentials, hashes, headers,
  full paths, environment maps, and arbitrary errors are excluded.
- [x] Browser mutations and export retain opaque sessions, exact Origin/
  Referer validation, CSRF, request limits, panic recovery, no-store, strict
  security headers, and escaped hostile content.
- [x] Ingestion remains on its independent listener, authenticates before
  expensive decoding, derives trusted Server identity from the token, commits
  atomically before success, and never logs payloads.
- [x] No telemetry, analytics, crash reporting, CDN, external font/script,
  production Node runtime, ordinary-operation outbound API, new service,
  database, or dependency was introduced.
- [x] Chromium/axe verifies the critical 0.4.0 browser flows in desktop/mobile,
  dark/light, keyboard/focus, and reduced-motion states.

The detailed threat/failure checklist and residual security boundary are in
`docs/security/0.4.0-hardening-review.md`.

## Known limitations and operator impact

- This is a pre-public implementation gate, not a release. There is no
  supported image, Compose deployment, Coolify installation guide, upgrade
  promise, release automation, tag, or `latest` publication yet.
- An actual Coolify host was not available. Pinned upstream configuration and
  production ingestion contracts are tested locally; operator deployment
  evidence belongs to SFT-052 and later dogfood gates.
- Production-container RSS/image size, `linux/arm64`, non-root mounted-volume
  behavior, the 10-million-event query gate, burst measurements, and capacity
  guidance belong to SFT-050/SFT-054.
- Long bounded soak evidence belongs to SFT-055. Several months of actual
  production dogfood cannot be manufactured by an automated test and remains
  a `1.0.0` evidence gate.
- Manual screen-reader, 200% zoom, non-Chromium browser, and final visual
  contrast review remain SFT-056 evidence. Automated semantics, axe,
  keyboard/focus, 390-pixel reflow, and dark/light coverage pass.
- Host/root/storage compromise can read or alter SQLite, rollback, backup,
  export, and bounded audit history. Protect the volume and artifacts and use
  host/volume encryption where required.
- An ingestion client disconnect after queueing has an intentionally ambiguous
  outcome; at-least-once retry and stable source event IDs remain the contract.
- The module-only unimported OpenPGP advisory is recorded above. There is no
  reachable Siftail vulnerability from that package.

No unresolved defect blocks the `0.4.0` implementation gate. The public
dogfood release remains blocked on the accepted SFT-050 through SFT-058 work.
