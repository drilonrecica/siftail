Keyboard shortcuts

Keyboard shortcuts are off, so single-key shortcuts do nothing. Esc and Ctrl K still work.

Everywhere

Ctrl K
Open the command palette (the palette button in the header)
?
Open this help (or System → Keyboard shortcuts)
Esc
Close the open overlay, or clear the selected row
{{if eq .KbScope "logs"}}

Logs workspace

F
Focus message search
H
Switch to History (the History tab)
L
Switch to Live (the Live tab)
J / K
Next / previous log row
Enter
Expand or collapse the selected row (its › toggle)
Space
Pause or resume Live (the Pause button; Live only)
G
Jump to the newest live event (the Jump to newest button)
{{else}}

Single-letter shortcuts are active only in the Logs workspace, so they can never interrupt form input here.

{{end}}

Every shortcut has a visible control that does the same thing.
